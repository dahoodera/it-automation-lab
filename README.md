# IT Automation Lab

A collection of scripts and projects I'm working on to improve my Bash, Python, and IT automation skills.

I've worked with Jamf, Kandji, Okta, and other IT tools throughout my career. I've also used scripts for application deployments, software updates, FileVault checks, password expiration checks, and user access audits.

I'm using this repository to get more hands-on with writing my own scripts and learning how to automate everyday IT tasks.

## Projects

### macOS Security Check
**File:** `security-check.sh`

My first Bash script. It checks:
- Current logged-in user
- macOS version
- FileVault encryption status

The script also uses an `if/else` statement to report whether FileVault is enabled.
